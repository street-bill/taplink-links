# taplink-links

Landingssider til showcards - én undermappe pr. forretning.

- URL-mønster: `https://street-bill.github.io/taplink-links/<forretning>/`
- Redigér HTML og push - siden opdaterer automatisk (GitHub Pages).
- Senere: kobl `links.taplink.dk` på via én CNAME-record hos simply.com -
  gamle URL'er bliver ved med at virke (redirect), så NFC-kort aldrig dør.
